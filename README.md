# 3D 麻将桌（Godot 4.7）

《重生2 / 重启人生》用的纯 Godot 3D 麻将小游戏。

## 运行

推荐双击 **`试玩入口.bat`**（桌面快捷方式：`3D麻将试玩`）。它会使用本机的 Godot 4.7.2 打开当前项目；如果 Godot 路径不同，可用命令行：

```
Godot_v4.7.2-stable_win64.exe --path . --resolution 1240x860
```

旧入口 `启动游戏.bat` 仍然保留。

## 内容

- `main.gd` —— 全部场景与规则流程（状态机驱动）
- `rules.gd` —— 胡牌判定与算分（小胡/碰碰胡/七对/龙七对/大吊车）
- `selftest.gd` —— 规则自测
- `faces/` —— 34 张牌面
- `sounds/` —— 音效与中文牌名播报

## 操作

- 启动进入主菜单，可选择开始游戏、规则与计分、设置或退出。
- 对局中在没有碰/杠响应时按 `Esc` 暂停；暂停菜单可继续、看规则、设置、返回主菜单或退出。
- 左键点击手牌出牌；悬停会显示牌名并轻微抬起。
- 出现响应提示时，点击按钮，或按 `P` 碰、`G` 杠、`Esc` 过。
- `R` 打开规则/计分面板，`M` 静音 / 恢复声音，`F11` 切换全屏。
- 规则面板内可切换 AI 难度：轻松 / 标准 / 挑战；难度会随比分一起保存。
- 设置面板可调主音量；音量、静音状态与比赛状态一起保存。
- 结算后点击“再来一局”进入下一局。

## 本桌规则

- 胡牌仅限**自摸**或**抢杠胡**，不能胡别人打出的牌。
- 庄家起手 14 张直接成牌时判**天胡**，按自摸计分。
- 自摸计分（底分 2）：小胡 4 分/家、碰碰胡 8、七对 16、龙七对 32。
- 杠分：暗杠 +6（其余三家各 -2）；放杠 +3（放杠者 -3）；碰后补杠 +3（其余三家各 -1）。
- 抢杠：被抢的杠不计杠分，杠者单独付 20 分给抢杠者，其他两家不付。
- 庄家胡牌连庄，其他家胡牌后由下家坐庄；流局连庄。
- 每个完整牌局结束后自动保存比分、庄家和局数到 `user://match_state.json`，每次杠后也会保存；重新打开游戏会继续。

## 已实现

- 主菜单、暂停、设置、退出与返回主菜单
- 广东麻将基本流程：摸 / 打 / 碰 / 杠；胡牌仅限**自摸**或**抢杠胡**，没有点炮胡
- 开桌成牌检查：庄家起手 14 张成牌自动判天胡
- 杠分即时结算：暗杠、放杠、补杠分别计分；抢杠改为杠者承包
- 多局比赛：四家累计分数、庄家轮转、连庄/流局、自动存档
- 三种杠：直杠、补杠、暗杠（补杠可被抢杠）
- 牌墙余牌逐张递减（奇数时破墙那墩只剩一张）
- 四家副露、牌河、手牌方向各自一致
- AI：轻松/标准/挑战三档；挑战档使用向听数选择弃牌，优先保留搭子并降低向听
- 语音：牌名播报 + 碰/杠/胡 人声（播报念完再喊）
- HUD：回合状态、牌墙/听牌信息、牌局记录、比分/庄家、规则面板、响应快捷键
- 结算：展示四家完整手牌，金框标出和牌张，并标明自摸/抢杠来源
- 交互与反馈：手牌悬停、响应按钮、轻量镜头反馈、发牌入场动画、杠分浮动数字、结算遮罩
- 音频总线：音效/人声分组，支持一键静音与主音量设置
